# ImageProcessing

## Summary

- _ImageProcessing_ is an image processing package.

## Language

- **Julia**

## Image File Format

- **PPM** (P3)
- **PGM** (P2)

## Installation

1. Start julia.

   ```shell
   $ julia
   ```

2. Push `]` key.

   ```julia
   julia> ]
   ```

3. Activate your project.

   ```julia
   (@version) pkg> activate .
   ```

4. Install this package.
   ```julia
   (your project) pkg> add https://github.com/terukichi/ImageProcessing.git
   ```
